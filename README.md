# Silent Wolf Labs Claude Marketplace

Open-source Claude plugins and agent skills from Silent Wolf Labs, distributed through a GitHub-hosted Claude Code marketplace.

This is a Silent Wolf Labs marketplace, not Anthropic's official marketplace.

## Install

Add the marketplace and install the dependency upgrade audit plugin:

```sh
claude plugin marketplace add Silent-Wolf-Labs/claude-marketplace
claude plugin install dependency-upgrade-audit@silent-wolf-labs
```

The `dependency-upgrade-audit` plugin is maintained in its own repository: [Silent-Wolf-Labs/dependency-upgrade-audit](https://github.com/Silent-Wolf-Labs/dependency-upgrade-audit).
